# sandbox

Genropy test and demo instance (`genropy` org).

- **Maintainer**: Davide Paci (`dgpaci`), who reviews PRs.
- **Target branch for PRs**: `master`. `develop` exists but has diverged from `master`: do not use it as a base.
- **Language**: English for issues, PRs, review comments, code comments and docstrings. Identifiers and commit messages in English.
- **Forge**: GitHub (`github.com/genropy/sandbox`), `gh` CLI. No CI configured. Open PRs with `gh pr create --base master --assignee @me`.
